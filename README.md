# Nishtha Patel’s Portfolio

[View the live portfolio](https://nishtha-portfolio-two.vercel.app/)

I’m a Computer Science student at Texas A&M University. This portfolio showcases my work in machine learning, full-stack development, and robotics.

## Featured projects

- **Visual Cortex Decoder** — Predicts visual stimulus direction from neural recordings using PyTorch and scikit-learn.
- **Thrive** — Explores personalized glucose forecasting and integrates the model with a React Native app built with Expo.
- **Milk Administration Dashboard V2** — A deployed full-stack dashboard built with Vue, TypeScript, and Supabase.
- **POBS** — Underwater robotics work on state estimation and navigation in ROS 2 and Gazebo.
- **ROS 2 Object Tracker** — Tracks a red object with OpenCV and publishes its position through ROS 2.

## Run locally

```bash
npm ci
npm run dev
```

Open [localhost:3000](http://localhost:3000) to view the site.

Built with Next.js, React, TypeScript, and Motion. Hosted on Vercel.
