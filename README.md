# Nishtha Patel’s portfolio

A Next.js portfolio for software engineering, machine learning, and robotics projects.

## Run locally

From the project folder, use Node.js 20.9 or later.

```sh
npm ci
npm run dev
```

Open http://localhost:3000.

## Validate and build

```sh
npm run lint
npm run build
```

Use `npm start` to serve the production build.

## Update the site

- Edit project descriptions, screenshots, and links in `src/app/projects.ts`.
- Edit the profile, contact links, and About section in `src/app/page.tsx`.
- Replace the résumé PDFs in `public/` using their existing filenames.
